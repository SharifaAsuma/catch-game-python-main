# 🍎 キャッチゲーム

IT部ミニアプリ開発会 - 中級コース用プロジェクト

## 📖 概要

60秒間で、上から落ちてくるアイテムをキャッチしてスコアを稼ぐゲームです。
Python + Pygameを使って、ゲームプログラミングの基礎を学べます。

## 🎮 ゲーム仕様

- **制限時間**: 60秒
- **操作**: ←→キーで左右移動
- **アイテム**:
  - リンゴ（赤）: +10点
  - バナナ（黄）: +15点
  - スイカ（緑）: +20点
  - 爆弾（黒）: -15点
- **難易度**: 中級者向け

## 🚀 クイックスタート

### 必要要件

- Python 3.8以上
- Pygame 2.5.2

### インストール

```bash
# リポジトリをクローン
git clone https://github.com/kpyuta/catch-game-python.git

# フォルダに移動
cd catch-game-python

# Pygameをインストール
pip install -r requirements.txt
```

### 実行

```bash
# 完成版を実行
python game.py

# テンプレート版で開発
python game_template.py
```

## 🐛 トラブルシューティング

### No module named 'pygame'

```bash
pip install pygame
```

### ウィンドウが開かない

```python
# pygame.init() を実行したか確認
# screen = pygame.display.set_mode(...) を実行したか確認
```

### アイテムが表示されない

```python
# draw() メソッドを実装したか確認
# pygame.display.flip() を呼んでいるか確認
```

### IndentationError

```
# インデント（字下げ）を確認
# 4スペースで統一
# タブとスペースを混在させない
```

詳しくは [GUIDE.md](GUIDE.md) のトラブルシューティングを参照してください。
